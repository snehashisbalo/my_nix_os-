# LazyVim Configuration (Omarchy-style)

This is a LazyVim-based Neovim configuration following the structure used in Omarchy.

## Structure

```
~/.config/nvim
├── init.lua           # Bootstrap LazyVim
├── lua/
│   ├── config/        # LazyVim config files (options, keymaps, autocmds, lazy)
│   └── plugins/       # Custom plugin specifications
└── lazyvim.json       # LazyVim extras and settings
```

## Installation

```bash
git clone <repo> ~/.config/nvim
nvim
```
